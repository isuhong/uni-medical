# 유엔아이메디컬 — 스마트 재고 관리 (VMI) 데모

병·의원 소모품 유통사(유엔아이메디컬) 관점의 **공급자 주도 재고 관리(VMI)** 웹앱 프로토타입입니다.
거래처별 소모품 사용·발주 데이터를 바탕으로 소진 시점을 예측하고, 적정 발주 시점·수량을 제안하며,
사용 패턴에 맞는 제품을 추천하고, 회사와 소통하는 창구를 제공합니다.

> 순수 정적(HTML/CSS/JS) 프로젝트입니다. 빌드 과정 없이 **GitHub Pages**에 바로 배포할 수 있습니다.
> 모든 데이터는 데모용 가상 데이터이며, 상태는 브라우저 세션 동안만 유지됩니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| **거래처 로그인** | 병·의원 계정(ID/PW) 기반 식별 |
| **재고 입력/조정** | 실물 재고 입력 시 소진 속도에 따라 상태(충분/임박/필요/결품) 자동 갱신 |
| **발주 추천** | 리드타임·안전재고를 반영한 발주 시점·수량 제안 + 예측 발주 일정 |
| **제품 추천** | 사용 패턴 분석 기반 신규·대체 제품을 **근거와 함께** 배너로 제안 (교차/상향 판매) |
| **소통창** | 제품 문의·품질 건의·신제품 요청 등 회사와의 커뮤니케이션 |

본사(공급자) 콘솔은 `uni-hq / uni-hq` 로 로그인해 확인할 수 있습니다.
관제 대시보드·거래처 관리·발주 파이프라인·실시간 재고 관리·제품 수요 분석·소통 인박스로 구성되며,
거래처 상세의 **'메시지 보내기'** 와 소통 인박스의 항목은 같은 거래처 채팅창으로 연결됩니다.

**실시간 재고 관리** 탭은 중앙물류센터의 SKU별 가용 재고·공급 커버리지와,
실시간 연동 거래처의 발주 필요 품목을 한 화면에서 봅니다.
데모에서는 4초마다 출고 이벤트를 시뮬레이션해 재고가 즉시 차감되는 모습을 보여주며,
실서비스에서는 WMS 출고 트랜잭션과 거래처 재고 동기화 이벤트가 이 자리를 대체합니다.

## 데모 계정

| 유형 | ID | PW |
|------|----|----|
| 대학병원 (3차) | `hy-univ` | `hanyang` |
| 종합병원 (2차) | `semyung-2` | `semyung` |
| 개인의원 (1차) | `mirae-clinic` | `mirae` |

각 계정은 규모에 맞는 서로 다른 품목 구성·사용 속도·재고 수준을 갖고 있어,
분석 엔진의 발주 예측과 추천 로직이 계정별로 다르게 동작하는 것을 확인할 수 있습니다.

## 실행

로컬에서 정적 서버로 열면 됩니다.

```bash
# Python
python3 -m http.server 8000
# 또는 Node
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

## 파일 구조

```
index.html        # 로그인 + 앱 셸 (전 화면)
css/style.css     # 스타일 (종이 베이스 + 파인그린 액센트)
js/data.js        # 제품 카탈로그 + 3개 거래처 데모 데이터
js/engine.js      # 소진 예측 · 발주 추천 · 제품 추천 로직
js/hq.js          # 본사 관제 콘솔 (관제·거래처·파이프라인·수요분석·소통 인박스)
js/app.js         # 화면 렌더링 · 상호작용
```

## 분석 로직 요약

- **소진 예측**: `잔여일 = 현재고 / 일평균사용량`
- **발주 권고 시점**: `소진일 − (리드타임 + 안전재고일)`
- **권장 발주량**: 적정 최대재고(par level)까지 채우되 발주 단위로 올림
- **제품 추천**: 협업 필터링(유사 거래처 보유율) → 주력 카테고리 확장 → 교차/상향 판매

## AI 적용 (데모 & 실서비스 매핑)

VMI·재고·추천 서비스에서 실제 쓰이는 AI를 세 층위로 반영했습니다. 데모는 백엔드 없이 규칙 기반으로 흉내 내되, 각 자리를 실서비스에서 어떤 모델이 대체하는지 UI에 명시합니다.

| 기능 | 데모 구현 | 실서비스 모델 |
|------|-----------|----------------|
| 수요 예측 | 일사용량 기반 소진일 계산 | Prophet + LSTM 앙상블 (거래처·SKU별 시계열) |
| 결품 예측 | 발주권고 잔여일을 로지스틱으로 변환한 '결품 위험 %' | Gradient Boosting(XGBoost) 분류 |
| 제품 추천 | 같은 종별 거래처의 SKU 보유율 기반 협업 필터링 근사 | 협업 필터링 + 콘텐츠 기반 하이브리드 |
| 운영 인사이트 | 규칙+집계로 생성한 자연어 카드 | LLM(요약·자연어 생성) |
| 이상 탐지 | (개념 명시) | 통계 + LLM 보조 |

거래처 대시보드/드릴다운의 **'결품 위험 %'**, 제품 추천 탭의 **'유사 거래처 분석'** 카드, 본사 관제 대시보드의 **'AI 인사이트'** 카드에서 각 기법이 동작합니다.
