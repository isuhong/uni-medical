# 유엔아이메디컬 — 스마트 재고 관리 (VMI) 데모

병·의원 소모품 유통사(유엔아이메디컬) 관점의 **공급자 주도 재고 관리(VMI)** 웹앱 프로토타입입니다.
거래처별 소모품 사용·발주 데이터를 바탕으로 소진 시점을 예측하고, 적정 발주 시점·수량을 제안하며,
사용 패턴에 맞는 제품을 추천하고, 회사와 소통하는 창구를 제공합니다.

> 순수 정적(HTML/CSS/JS) 프로젝트입니다. 빌드 과정 없이 **GitHub Pages**에 바로 배포할 수 있습니다.
> 모든 데이터는 데모용 가상 데이터이며, 상태는 브라우저 세션 동안만 유지됩니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| **거래처 로그인** | 병·의원 계정(ID/PW) 기반 식별 |
| **재고 입력/조정** | 실물 재고 입력 시 소진 속도에 따라 상태(충분/임박/필요/결품) 자동 갱신 |
| **발주 추천** | 리드타임·안전재고를 반영한 발주 시점·수량 제안 + 예측 발주 일정 |
| **제품 추천** | 사용 패턴 분석 기반 신규·대체 제품을 **근거와 함께** 배너로 제안 (교차/상향 판매) |
| **소통창** | 제품 문의·품질 건의·신제품 요청 등 회사와의 커뮤니케이션 |

## 데모 계정

거래처(병·의원)와 본사(유엔아이메디컬) 두 종류의 계정이 있으며, 화면이 완전히 다릅니다.

**거래처 계정** — 내 재고 한 곳을 관리하는 뷰

| 유형 | ID | PW |
|------|----|----|
| 대학병원 (3차) | `hy-univ` | `hanyang` |
| 종합병원 (2차) | `semyung-2` | `semyung` |
| 개인의원 (1차) | `mirae-clinic` | `mirae` |

**본사(공급자) 콘솔** — 전 거래처를 가로질러 관리하는 VMI 관제 뷰

| 유형 | ID | PW |
|------|----|----|
| 유엔아이메디컬 본사 | `uni-hq` | `uni-hq` |

각 거래처 계정은 규모에 맞는 서로 다른 품목 구성·사용 속도·재고 수준을 갖고 있어,
분석 엔진의 발주 예측과 추천 로직이 계정별로 다르게 동작하는 것을 확인할 수 있습니다.

## 본사(HQ) 콘솔 기능

공급자 관점의 VMI 관제 콘솔로, 거래처 뷰(파인그린)와 구분되는 딥네이비 테마입니다.

| 화면 | 설명 |
|------|------|
| **관제 대시보드** | 1,500개 거래처 총계 KPI(매출·활성·충족률) + AI 인사이트 카드(결품 리스크/매출 기회/운영 성과) + 주의 거래처 |
| **거래처 관리** | 상태별 필터(위험/주의/정상), 거래처 목록 드릴다운. 실계정은 실시간 재고까지 열람 |
| **발주 파이프라인** | 전 거래처 발주 요청 → 배송 → 완료 흐름 관리, 발주 승인 |
| **제품·수요 분석** | SKU별 월 출고·추세·회전율·폐기율·추천 성과 (신제품 기획/수요 예측 근거) |
| **소통 인박스** | 거래처가 보낸 문의·건의를 카테고리별로 관리 (거래처 소통창의 본사측 뷰) |

## 실행

로컬에서 정적 서버로 열면 됩니다.

```bash
# Python
python3 -m http.server 8000
# 또는 Node
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

## 파일 구조

```
index.html        # 로그인 + 거래처 앱 셸 + 본사(HQ) 콘솔 셸
css/style.css     # 스타일 (거래처: 파인그린 / 본사: 딥네이비)
js/data.js        # 제품 카탈로그 + 거래처 데모 데이터 + 본사 관제 데이터(거래처 풀·SKU 지표·인박스·AI 인사이트)
js/engine.js      # 소진 예측 · 발주 추천 · 제품 추천 로직 (양쪽 공용)
js/app.js         # 거래처 앱 렌더링 · 상호작용 · 로그인 라우팅
js/hq.js          # 본사 관제 콘솔 렌더링 · 상호작용
```

## 분석 로직 요약

- **소진 예측**: `잔여일 = 현재고 / 일평균사용량`
- **발주 권고 시점**: `소진일 − (리드타임 + 안전재고일)`
- **권장 발주량**: 적정 최대재고(par level)까지 채우되 발주 단위로 올림
- **제품 추천**: 주력 카테고리 확장 → 회전 빠른 품목의 인접 규격(교차판매) → 재활 상향판매

실제 서비스에서는 규칙 기반 로직을 거래처별 시계열 수요예측 모델로 대체하는 것을 상정합니다.
